# Task3. Архитектура флагманского сервиса

## Решение кратко

- C4 Container и Component разграничивают модель, обычный код, политику очереди и сотрудника.
- Асинхронный расчёт идемпотентен; при сбое сохраняется исходная очередь.
- Выход валидируется до изменения порядка. Модель не выполняет действий над клиентом.
- Пять границ доверия TB1–TB5 отмечены на схемах и связаны с таблицей угроз.
