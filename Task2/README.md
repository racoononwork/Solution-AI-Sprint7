# Task2. Данные, размещение и модель флагмана

## Решение кратко

- Готовность данных: **«Разрыв с планом закрытия»**. Операции доступны, но приоритетность нужно разметить заново; эскалации и подтверждённые схемы не подменяют новую метку.
- Пилот и целевой прод размещаются в контуре банка без внешних модельных API. Перенос в облако возможен только после отдельного допуска и пересмотра ADR.
- Для сравнения оставлены линейный baseline, CatBoost и LightGBM LambdaRank. Победитель выбирается на вероятностном и сценарном наборах, а не по публичному рейтингу.
