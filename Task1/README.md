## Решение кратко

- Все 18 инициатив получили вердикт, обоснование и, при неоднозначности, уточняющий вопрос.
- Сравнены четыре кандидата: №1, №2, №15 и №18.
- Для проработки выбраны №1 «Подозрительные операции», №2 «Оцифровка сканов» и №18 «Извлечение финансовых показателей». №15 оставлен резервом.
